# AA-940 (CRM-12) — AA-Partner audit export: grant, variables, alarms

Card CRM-12 (root `docs/audits/2026-10-21-S246-crm-design-v3/design-v3.md` §6.3, §4.9 "hourly to both Object Lock
buckets, with a chained SHA-256 manifest"). AA-Partner branch `feat/aa-940-f5-audit` writes one object per agency per
closed UTC hour to both audit tiers (`api/app/audit_export`); the buckets exist since AA-932 (`crm_storage.tf`). This
branch (`feat/aa-940-audit-export`, from `main`) lets the task role use them. The migration copy is on
`chore/aa-940-crm-007-copy`.

## Decisions

- **A separate role policy** (`crm_storage.tf` `aws_iam_role_policy.crm_ecs_task_audit_export`) instead of two more
  statements in `crm_app.tf` `crm_ecs_task`: the AA-937 documents grant edits that policy in parallel; two policies
  on one role are evaluated together, so the effect is the same and the branches do not collide.
- **PutObject + GetObject under `audit/v1/tenants/*` only.** GetObject is for the app's verification (the daily
  retention re-reads both copies before any partition may drop). No List (a missing object then answers 403, which
  the app treats as missing), no delete, no retention / legal-hold / bypass actions: every version the app writes is
  locked by the bucket default (GOVERNANCE 365 days on audit-c on Dev, 7 years on audit-g). The CI apply boundary's
  `DenyCrmAuditObjectTampering` is unchanged.
- **SSE-KMS** under the ingest key through S3 only and bound to the two audit bucket ARNs, the same conditions as the
  key policy's `CrmRuntimeS3Objects` (both must allow).
- **Task definition**: `AUDIT_BUCKET_COMPLIANCE`, `AUDIT_BUCKET_GOVERNANCE` (bucket names, not ARNs; the public app
  repo never sees the account id) and `AUDIT_RETENTION_DRY_RUN=true` (DM-7.2). Reaches the task on the next
  AA-Partner deploy (the deploy copies the latest revision).
- **Alarms** on the API sampler's metrics (namespace `AA/Jobs/Crm`, no IAM change): `aa-crm-dev-audit-export-lag`
  (`AuditExportLagMinutes` >= 180 for two periods) and `aa-crm-dev-audit-partitions`
  (`AuditPartitionMonthsAhead` < 1). Missing data = OK.

## Cost

About $0.85/month on Dev: PUTs ~1,440 per agency per month (~$0.007 each agency), GETs ~$0, storage a few KB per
object, KMS in the free tier (Bucket Keys), 2 alarms ($0.20) + 2 custom metrics ($0.60). At 100 agencies about
$0.75/month more in PUTs.
