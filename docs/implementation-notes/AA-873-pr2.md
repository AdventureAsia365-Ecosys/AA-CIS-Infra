## Decisions

- **Object Lock on the existing bucket, no replacement.** Path: `aws_s3_bucket_versioning` (Enabled) then
  `aws_s3_bucket_object_lock_configuration` with `object_lock_enabled = "Enabled"`, GOVERNANCE 365 days
  (`depends_on` versioning). `aws_s3_bucket.cloudtrail_logs` keeps `object_lock_enabled` unset.
  Verified offline with provider hashicorp/aws 6.69.1 (fake credentials, `plan -refresh=false` on a crafted state):
  attribute Optional + Computed; unset -> "No changes" whether the state says false or true; set false -> true ->
  update in-place, not replace. Not set anyway: the bucket update would run before versioning and fail. Probe kept
  in the root workspace `.tmp-session/S255/infra/provider_probe/`.
- **Key policy without the AWS-console "any principal in the account may decrypt" statement** (the draft had it):
  account root `kms:*` (IAM decides), CloudTrail `GenerateDataKey*` with `aws:SourceArn` = this trail and the
  CloudTrail encryption context, CloudTrail `DescribeKey` with the same SourceArn. Reading log files then needs an
  IAM grant (the MFA admin role has one).
- **Lifecycle replaced in place** (same resource address): the Deep Archive transition never ran (128 KB minimum,
  files ~62 KB) and would cost more than it saves. New rule: noncurrent versions expire after 400 days (after the
  365-day lock), incomplete multipart uploads after 7 days. Current versions never expire (AA-286).
- **Multi-region trail**: the first copy of management events is free in every region; it also makes the PR 1
  us-east-1 forwarder reliable for IAM and root events.
- **Bucket policy unchanged**: every regional copy writes with `aws:SourceArn` = the home trail ARN, under
  `AWSLogs/<account>/`.

## Tradeoffs

- GOVERNANCE, not COMPLIANCE: the MFA admin can still remove a version with `s3:BypassGovernanceRetention` (Dev,
  D-09; `plan_guard.py` refuses COMPLIANCE). The CI apply role has AmazonS3FullAccess, which includes the bypass;
  denying it for this bucket in the apply boundary (like `DenyCrmAuditObjectTampering`) is a follow-up bootstrap edit.
- Object Lock can never be turned off on this bucket. Deleting the bucket later needs every version to age out.
