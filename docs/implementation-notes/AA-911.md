# AA-911: Cognito callbacks and DNS for the fixed staff Preview hosts

Root ADR 0006a A11 (S246): one fixed Preview host per staff app, registered once as a WORKFORCE callback and
sign-out URL on the existing app client. This branch (`feat/aa-911-preview-callback`) is the callback + DNS PR.
The bridge-era `booking.staff_users` script is a separate PR (`docs/implementation-notes/AA-911-staff-rows.md`).

## Decisions

- **Hosts:** `booking-preview.lumiguides.it.com` (Vercel `aa-booking-admin`, client `booking-staff`) and
  `aa-cis-preview.lumiguides.it.com` (Vercel `aa-cis-frontend`, client `cis-admin`). Paths follow the apps:
  callback `/api/auth/callback/cognito`, sign-out `/login`.
- **`breakglass` is unchanged**: break-glass sign-in stays on Production only.
- **Same app clients, no new `*-preview` client** (deferred until before prod / the first paying tenant): a new
  client would mean a new client_id in both frontends and verifiers, its own branding, and a new secret.
- **DNS targets** come from Vercel `get_domain_config` (`recommendedCNAME` rank 1) for each project, read
  21/10/2026: they equal each project's existing target (`booking.` and `aa-cis.`). The takeover rule in the
  variable description still holds: add the domain to the Vercel project BEFORE applying this.
- **ECS task policy comment**: `booking-jwt-signing-key` is dropped from the "CIS code reads" list (comment
  only, no IAM change; the secret is read by `GetSecretValue` on `*`, and it is deleted by the orchestrator after
  the CIS bridge removal is live).

## Changed

- `accounts/aa365/identity_variables.tf`: two callback + two sign-out URLs, description.
- `accounts/aa365/custom_domains_variables.tf`: two Vercel CNAMEs (`booking-preview`, `aa-cis-preview`).
- `modules/ecs/main.tf`: comment only.
- `CONTEXT.md`: the Vercel hosts line.

## Tradeoffs

- One shared Preview host per app means one preview at a time can be signed in to; fine for Dev.
- Re-using the production clients means a preview build holds the real client secret (Preview target of the
  Vercel env var). Accepted for Dev; ADR A11 names the trigger for a separate client.
