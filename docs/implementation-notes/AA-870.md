# AA-870 — CIS error visibility (Terraform part)

## Decisions
- 5XX alarm by count (>= 5 in 5 min), not by rate: Dev had 3,641 requests and 3 5XX in the week to 17/10/2026, so a
  rate alarm would fire on 1 error in 2 requests. Same shape as the Booking API alarm.
- Latency: IntegrationLatency p95 > 5 s for 3 consecutive 5-minute periods. Measured week: p95 per 15-min window
  median 290 ms, 99th percentile 4.8 s, max 6.9 s; no window above 10 s.
- ALARM and OK actions (D-20), missing data = not breaching (C4.1a).
- Module api_gateway gains `api_name` / `stage_name` outputs for the metric dimensions.
