- Owner decision S245: the CIS → Booking bridge stays (Booking previews need it); AA-680 closes on evidence that a
  WORKFORCE user with no `booking-*` group is refused. This repo adds the database half of that evidence; the
  browser half is the CIS Cognito E2E (AA-CIS-App `e2e-cognito.yml`, Booking step 4b).

  Booking code path would be found.
- The run fails (return 1, exit 13) only when a Booking row matches the E2E identity: that would contradict the
  refusal evidence. A missing E2E user (AA-816 A10 may disable/remove it later) is reported, not failed.

- Prints CIS usernames and CIS uuids (same as the link script) so the reader can tell whose row is unlinked;

- The local CLI does not force a read-only session (the runner's shape check refuses any string literal naming
  the read-only setting); DB Migrate enforces it through `READ_ONLY = True`.
