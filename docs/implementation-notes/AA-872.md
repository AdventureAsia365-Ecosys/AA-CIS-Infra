# AA-872 — alarm OK e-mails + log retention by class

## Decisions
- Every CloudWatch alarm on the shared topic gets `ok_actions` = the same topic (29 added; identity.tf already had them).
  ECS target-tracking alarms are owned by Application Auto Scaling and are left alone.
- Retention classes (S241 D-09): security/audit 365 days = VPC flow logs, WAF logs, ECS Exec session transcripts,
  RDS postgresql log (connection/disconnection lines, AA-824); the Cognito trigger Lambdas were already 365.
  App logs 30 days = ECS CIS + Booking, TripPlanner Lambdas, DFS balance Lambda, CIS API Gateway execution log.
- `/aws/apigateway/welcome` (empty, created by API Gateway, not in Terraform) is left as is.

## Cost (D-19), measured 10–17/10/2026
| Group | Ingest/day | Before | After |
|---|---|---|---|
| VPC flow logs | 58.6 MB | 7 d | 365 d |
| WAF logs | 49.8 MB | 30 d | 365 d |
| API GW execution | 12.9 MB | 14 d | 30 d |
| ECS CIS | 5.8 MB | 14 d | 30 d |
| others | < 1 MB | 14/30 d | 30/365 d |
Ingest cost is unchanged. Stored bytes grow to roughly 15 GB compressed after 12 months (flow + WAF dominate),
about 0.5 USD/month at 0.03 USD/GB-month; month one adds a few cents.

## Tradeoffs
- OK e-mails double the mail per flap (AA-833). Nghiệp chose them (D-20); fix thresholds, not actions.
