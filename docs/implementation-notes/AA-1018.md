# AA-1018 — Infra: daily LLM connection probe on

Source: AA-CIS-App `services/jobs/llm_probe_job.py` + `api/core/ops_metrics_sampler.py` (CIS PRs #1198, #1210), AI
gateway design decision 2 (S261: the probe is approved at under 1 USD a month).

## Decisions
- `LLM_DAILY_PROBE=on` on the CIS **api and worker** task definitions through a new `modules/ecs` variable
  `llm_daily_probe` (bool, default false) and `local.llm_daily_probe_env`, the `PLACE_PIPELINE_AUTO` pattern. Set
  `true` in `accounts/aa365/main.tf`. Both services need it: the api's ops metrics sampler is what queues the daily
  `llm_connection_probe` job (and the admin's live run is refused with the switch off), and the job re-checks the
  switch on the worker before any call (`NonRetryable` when off). Accepted values in the app: `on/true/1/yes`; the
  module writes `on` / `off`.
- No probe-scope knob exists (only the switch, `SCHEDULE_HOUR_UTC = 5`, `MAX_PROBES = 30`, 32 output tokens per call,
  all constants), and none is needed: the estimate is well under the 1 USD a month line.

## Cost estimate (catalog prices, the job's own formula)
Per probe: `(60 input tokens x price_in + 32 output tokens x price_out) / 1e6`. Probed: every enabled text deployment
on every enabled connection without a policy problem (embedding rows and disabled deployments are skipped).

| Connection | Deployments probed | USD a day |
|---|---|---|
| acc2 | nova-lite, nova-2-lite, llama4-maverick, llama4-scout, kimi-k3 (haiku / sonnet deployments disabled) | 0.00095 (kimi-k3 0.00073) |
| acc3 | haiku, sonnet, gpt-5.6-luna, gpt-6-astra, gpt-6-luna, sonnet-5, opus-5-5, haiku-5-5, sonnet-5-5 | 0.00493 |
| openai-direct | gpt-6-luna-openai, gpt-4.1 | 0.00040 |
| anthropic-direct, bedrock-llm-org | none (connection disabled) | 0 |

Worst case (every probe answers): about 0.0063 USD a day, about 0.20 USD a month (31 days). Today acc3 refuses at
0 USD, so the real figure is about 0.0013 to 0.002 USD a day (the S262 live acc2 run of the five candidates cost about
0.0016 USD in total). If anthropic-direct is switched on later it adds about 0.0018 USD a day (0.06 a month).
