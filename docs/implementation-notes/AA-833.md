# AA-833 — TripPlanner Lambda throttle alarms: page only on sustained throttling (S238)

Infra half of AA-833. The TripPlanner half (no prefetch on card grids, one retry in `browseGet`)
is in AA-TripPlanner-Web, branch `fix/aa-833-prefetch-fanout`. The root cause of the real
throttles (slow `catalog.v_tour_place`) was fixed by CIS migration 235.

## Decisions

- **Threshold**: `Sum(Throttles) > 5` per 300 s, `evaluation_periods = 3`,
  `datapoints_to_alarm = 2` (2 of 3, so 10-15 minutes of throttling before it pages).
  `treat_missing_data = notBreaching` kept (Lambda publishes no datapoint when idle).
- **No `ok_actions` on these two alarms.** The noise was 7 flips = 14 emails (ALARM + OK). Every
  other alarm in `observability_ecosys.tf` keeps its OK action; these two are the exception and
  the resource comment says why. Recovery is still visible in the console and
  `describe-alarm-history`.
- Same change for browse and assembly (one `for_each` resource). Other alarms unchanged.

## Changed

- `accounts/aa365/observability_ecosys.tf`: `tripplanner_lambda_throttles` thresholds, M-of-N,
  description, `ok_actions` removed.
- `CONTEXT.md`: observability line names the new rule.

## Tradeoffs

- A short burst of throttles (one 5-minute period, or fewer than 6 throttles per period) no longer
  pages. Callers see those as 429/503; the TripPlanner frontend now retries once, and the Lambda
  `Errors` alarm and RDS alarms are unchanged.
- Dropping `ok_actions` means a real incident sends one email, not two, and nobody is told when it
  ends. Accepted for a dev, email-only topic.

## Should know

- Plan should show 2 in-place updates (`aws_cloudwatch_metric_alarm.tripplanner_lambda_throttles["browse"]`
  and `["assembly"]`), nothing else. Not planned or applied from this lane.
- Removing `ok_actions` from config makes the provider send an empty `OKActions` list, which
  clears the existing OK action on apply (verify with `describe-alarms` afterwards).
- `docs/implementation-notes/AA-678-s235-p0-observability.md` still says `Throttles > 0`: that is
