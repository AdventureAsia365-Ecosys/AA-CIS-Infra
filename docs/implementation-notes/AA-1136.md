# AA-1136 — agent change hooks, AA-CIS-Infra part (S285 lane l20-hooks-specs-apps)

The root repo holds the checker and the Claude Code hooks (`tools/sync/change_guard.py`, `.claude/hooks/`, root PR
of S285, log mode). This repo gets the CI jobs `notes-present` / `test-cochange` at WARN level. The `--select-only` mode of
the pre-push test selector is a CIS and Booking piece only (their selectors pick unit tests per changed file; this
repo's pre-push has no such selector).

## Decisions

- **One workflow, two jobs, warn only** (`.github/workflows/change-guard.yml`): a matrix over `notes-present` and
  `test-cochange`, each running `change_guard.py check --json` on the PR checkout and turning its own finding into a
  warning annotation and a job-summary line. The jobs always end green; they are not required checks.
- **The checker comes from AA-Ecosys, pinned.** A sparse checkout of `tools/sync` at the same root commit that
  `spec-trace.yml` pins, in a folder beside the app checkout (not inside it), so the checker never counts its own
  files as a change of the PR. Re-pin both files together, in all five app repos at once.
- **Issue id as on a laptop.** The job names a local branch `pr/<head ref>`, so the checker reads the issue id from
  the branch name and the `Refs AA-<n>` lines of the commits, exactly as the Stop hook does in a lane worktree.
- **Blob-less full clone** (`fetch-depth: 0`, `filter: blob:none`, `diff.renames false`): the merge base needs the
  history, the checker needs only file names, and rename detection would fetch contents.
- **Skips**: merge groups (the PR run already reported) and bot branches (`bot/`, `release-please--`, `dependabot/`).
  Not by `user.type`: the orchestrator's GitHub App is a Bot too, and its PRs are the ones to measure.

## Changed

- New `.github/workflows/change-guard.yml`. No app code changes.

## Tradeoffs

- No sticky PR comment (the advisory's idea): annotations and the job summary need only a read-only token; a comment
  would need `pull-requests: write` for a warning nobody has to act on yet.
