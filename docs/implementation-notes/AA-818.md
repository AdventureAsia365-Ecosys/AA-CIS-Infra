# AA-818 — Custom domains for AA-Booking and TripPlanner (Infra half, S237 lane infra #3)

## Decisions

- **Single owner of the AA-818 Terraform** (S237 cross-lane edit): this PR holds every cert, API GW
  domain and DNS record. The TripPlanner and Booking lanes do only Vercel project domains, app env,
  CORS, canonical and the Mapbox URL restriction.
- **DNS in Route 53, not Namecheap** (S237 D5, AA-811 zone `aws_route53_zone.lumiguides`): validation
  CNAMEs, A alias records and Vercel CNAMEs are `aws_route53_record`s. Nothing in the zone is served
  until Nghiep switches the nameservers.
- **Two SAN certificates:**
  - us-west-1 `api-booking.lumiguides.it.com` + SAN `api-tripplanner.lumiguides.it.com` (both API GW
    REGIONAL domains need a cert in the API's region);
  - us-east-1 `auth.lumiguides.it.com` + SAN `staff-auth.lumiguides.it.com` (Cognito custom domains
    are served by CloudFront, which only takes us-east-1 certs; ADR 0006 decision 10). Output
    `auth_custom_domain_certificate_arn` feeds AA-703 `var.identity_custom_domain_certificate_arn`.
  - No wildcard: a `*.lumiguides.it.com` cert would also cover hosts nobody reviewed, and SANs cost
    nothing extra.
- **Provider alias `aws.us_east_1`** in `versions.tf`, same default tags as the main provider.
- **Gate `var.custom_domains_enabled` (default false)** on everything that needs an ISSUED cert or
  serves traffic: the two `aws_acm_certificate_validation` waits (they would block an apply for up to
  75 min before the NS switch), the REST domain + empty base path mapping (Booking), the HTTP API
  domain + API mapping (TripPlanner), the two A alias records and the Vercel CNAMEs. Certificates and
  validation records are unconditional: after the switch ACM validates on its own, with no apply.
- **Empty base path / no API mapping key**: Booking routes already start at `/booking`, TripPlanner at
  `/browse` and `/trip`, so the public paths equal the execute-api paths minus the stage.
- **A alias records** (not CNAMEs) for the API hosts: free queries, no TTL to manage.
- **Vercel frontends as a map `custom_domain_vercel_hosts`** (label => CNAME target), default
  `{ tripplanner = "cname.vercel-dns.com" }`. The Booking staff admin host (`booking.`, Linear scope
  item 1) is not in the default because its name is not confirmed yet (S237 lane edit "if Nghiep wants
  one"); it is a one-line tfvars addition.
- **TLS_1_2** security policy on both API domains, RSA 2048 keys (Cognito accepts RSA 2048 only).

## Tradeoffs

- **One gate for APIs and frontends vs one per host:** a single switch keeps the post-NS-switch step
  to one tfvars line. The cost: the Vercel CNAME and the API domains go live together, so the Vercel
  project domain must be added before the flag flips (see Should know).
- **Validation waits gated vs unconditional:** unconditional waits would make every apply before the
  switch hang and fail after 75 min. Gated, the domain resources still depend on the wait, so they
  cannot be created on a PENDING cert.
- **`stage = aws_apigatewayv2_stage.tripplanner.id` (reference, not the literal `$default`):** correct
  ordering, but a targeted apply of the TripPlanner mapping pulls in the TripPlanner stage -> routes ->
  integrations -> Lambda functions, so it also applies any Lambda drift (see Should know).

## Should know

- **Targeted plans (15/10/2026, local, aa365-admin, `-lock=false`):**
  - flag off, `-target` certs + validation records: **6 to add, 0 to change, 0 to destroy**
    (2 certs, 4 validation CNAMEs).
  - flag on, all AA-818 targets: 15 to add, **4 to change** — the 4 changes are NOT from this PR:
    `aws_lambda_function.tripplanner_{browse,assembly}` `reserved_concurrent_executions 5 -> -1` (the
    interim hand cap from 15/10 01:40Z) and `aws_s3_object.tripplanner_{browse,assembly}_zip`
    `tags_all` (default tags). They come in as dependencies of the TripPlanner API mapping.
    **Do not run the round-2 apply until AA-824 (encodes reserved concurrency 5) is merged and applied**,
    or the apply removes the Lambda concurrency cap. Re-plan and check "0 to change" on the Lambdas.
- The certs stay `PENDING_VALIDATION` until the NS switch. ACM keeps trying for 72 h; after that a cert
  becomes `VALIDATION_TIMED_OUT` and must be replaced (`terraform apply -replace=aws_acm_certificate.api`).
  So apply round 1 close to the switch, or re-request if the switch slips by more than 3 days.
- A CNAME to Vercel with no Vercel project claiming the host is a sub-domain takeover risk: add
  `tripplanner.lumiguides.it.com` to the `aa-tripplanner` project first (Vercel shows the exact target;
  if it is project-specific like `aa-cis`'s `*.vercel-dns-017.com`, set it in
  `custom_domain_vercel_hosts`), then flip the flag.
- The Cognito custom domains also need an apex A record (ADR 0006 decision 10, dns-parity.md gap 4).
  That record and the `aws_cognito_user_pool_domain` resources belong to AA-703 (`identity.tf`).
- Post-NS-switch steps (ordered):
  1. `aws acm describe-certificate` on both ARNs (output `custom_domain_certificates`, us-west-1 and
     us-east-1) until `ISSUED`.
  2. AA-824 applied (Lambda reserved concurrency in code).
  3. Vercel: add `tripplanner.lumiguides.it.com` to `aa-tripplanner` (and `booking.` to
     `aa-booking-admin` if approved, plus its map entry).
  4. `custom_domains_enabled = true` in `terraform.tfvars` (PR) → targeted plan (expect 9 to add,
     0 to change) → targeted local apply.
  5. Verify: `curl -s -o /dev/null -w '%{http_code}' https://api-booking.lumiguides.it.com/booking/health/ready`
     → 200; `curl https://api-tripplanner.lumiguides.it.com/browse/search?q=vietnam` → 200, same JSON as
     the execute-api URL; `curl -sI https://tripplanner.lumiguides.it.com/` → 200 with a valid cert.
  6. App lanes: TripPlanner `NEXT_PUBLIC_SITE_URL` + BFF base URLs, Booking `BOOKING_API_URL`, CORS
     origins, Mapbox URL restriction — underscore env vars are edited by hand in Vercel.
  7. AA-703: `identity_custom_domain_certificate_arn = <output auth_custom_domain_certificate_arn>` +
     apex A record + `identity_custom_domains_enabled = true`.
