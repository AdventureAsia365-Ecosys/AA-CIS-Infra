# AA-59 — WAF Terraform Module

## Decisions
- GeoBlock country list taken from spec verbatim: US, GB, AU, SG, HK, AE, SA, CA, NZ, DE, FR, JP, TH, VN, MY, ID, PH. Not validated against actual AWS console state — verify before apply.
- Rule priority order: RateLimit(1) → ManagedCommon(2) → GeoBlock(3). Rate limiting fires first so a blocked IP doesn't consume geo evaluation.
- CloudWatch log group name `aws-waf-logs-*` required by WAF logging — AWS enforces this prefix for WAF log destinations.

## Changed
- Logging config and log group are **not** imported (they don't exist yet on AWS). Only `aws_wafv2_web_acl.main` and `aws_wafv2_web_acl_association.alb` are imported.

## Tradeoffs
- Hardcoded ALB ARN in root `main.tf` (same pattern as `alb_dns_name` in api_gateway module). Alternative was `module.alb.alb_arn` output — skipped because alb module outputs aren't confirmed without reading it.

## Should know
- Import IDs: WAF ACL uses `{id}/{name}/{scope}` format. Association uses the resource ARN directly.
- If plan shows `destroy` on `aws_wafv2_web_acl.main` → STOP. It means config drifted from real AWS state (likely GeoBlock country list or rule names).
