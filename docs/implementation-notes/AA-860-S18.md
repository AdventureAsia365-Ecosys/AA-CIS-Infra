## Tradeoffs
- No `default_value` on the metric: no datapoints while quiet (≈ $0 custom-metric cost), and
  `treat_missing_data = notBreaching` keeps the alarm OK.
- The filter matches the log text, not a structured field: asyncpg's `TooManyConnectionsError` message is
  `too many connections for role "cis_app"`; any log line carrying it (uvicorn traceback, structlog error,
  job failure) counts.

## Cost (monthly)
- 1 alarm ≈ $0.10; the custom metric ≈ $0.30 only in months where it publishes (it publishes only on a match);
  metric filter itself free. ≈ $0.10–0.40/month.
