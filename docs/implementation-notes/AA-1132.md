# AA-1132 — Docs impact caller (slice A4)

The full notes of the docs sync engine are in the AA-Ecosys root repo, `docs/implementation-notes/AA-1132.md`.

## Decisions

- This repo adds only `.github/workflows/docs-impact.yml`, a caller of the root reusable workflow
  `AA-Ecosys/.github/workflows/docs-impact.yml`. The doc map and the tool live in the root (tech lead S283: one central
  map) and are read from root master at run time, so a map change needs no change here.
- Warn only: the job posts one sticky PR comment and warning annotations, exits 0, and is never a required check.

## Changed

- Nothing in the app code.

## Tradeoffs

- The reusable workflow is pinned to a root commit (workflow lint WL6, org setting for SHA pins); the root repo has no
  release tags, so the trailing comment is the date of that commit. Only a change of the root workflow file needs a
  re-pin here.

## Should know

- The job listens to `pull_request` and `merge_group` without a `paths:` filter (merge-queue rule); on `merge_group`
  the called job is skipped, so a queue group never waits on it.
- Answer a warning with one line in the PR body: `Docs-impact: <AA-Ecosys PR link>`, `Docs-impact: updated-here` or
  `Docs-impact: none: <reason>`.
