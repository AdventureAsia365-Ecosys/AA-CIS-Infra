# AA-972 (CRM-B1) — Cognito M2M pool for AA-Partner → AA-Booking, and the bk-019 copy

Root ADR 0006b decision 7 (M2M pool for service callers), contract `booking.b2b.v1`. The Booking half (M2M token
check, B2B quote API, migration bk-019) is AA-Booking PR `feat/aa972-m2m-b2b-quote`; this PR holds the resources and the
byte-identical migration copy. Session S248, agent Claude Code.

## Decisions

- **One new file, `accounts/aa365/identity_m2m.tf`** (pool `aa-m2m-dev`, resource server `booking.b2b`, client
  `aa-m2m-dev-crm`, prefix domain, secret container), next to `identity.tf` but independent of it: no trigger, no SES,
  no WAF, no branding, no custom domain (the token endpoint is never shown to a person; ADR 0006b).
- **Pool**: Essentials like the other pools (0 MAU: there are no users), deletion protection ACTIVE, admin-create only,
  MFA off, recovery admin-only.
- **Client**: confidential, `client_credentials` only, the four contract scopes `booking.b2b/{read,quote,hold,book}`
  (Booking checks one scope per route; hold/book routes come with AA-973, so they grant nothing yet and AA-973 needs
  no Infra change), access tokens 6 h (`identity_m2m_access_token_minutes`, ADR 0006b "tokens live 6 h, cached in
  process"), `explicit_auth_flows = ["ALLOW_REFRESH_TOKEN_AUTH"]` only (no SRP / password / USER_AUTH).
- **Booking wiring without copied ids**: `booking.tf` passes `COGNITO_M2M_ISSUER` (from the pool endpoint) and
  `COGNITO_M2M_CRM_CLIENT_ID` (from the client) to the task definition. The service ignores task-definition changes;
  the next Booking deploy copies the latest revision, so the B2B API turns on with that deploy.
- **Secret container `aa-crm/dev/m2m-booking-client`**, tagged `App = crm` (CRM naming contract, `cicd_crm.tf`), with no
  value: Terraform writes no `secret_version`, so the plan role reads no secret value on refresh and
  `local.tf_plan_secret_arns` is unchanged. The value (client id + secret + token URL + scopes) is written once after
  apply, straight from Cognito into Secrets Manager (handoff command), never through a file or a terminal echo.
- **Cost** (stated before apply, D-19; list prices as known, AA-930 confirms): ≈ 6 USD per M2M client-month + token
  requests (cents with 6 h caching) + 0.40 USD for the secret ≈ **6.5 USD / month** on Dev.

## Tradeoffs

- Granting all four scopes now vs. least privilege per card: one MFA/apply round instead of one per Lane B card; the
  receiver's per-route scope check is what limits access.
- No CIS resource servers (`cis.catalog`, `cis.tenant`) yet: their receivers do not exist (AA-976, AA-978 add them in
  this file).
