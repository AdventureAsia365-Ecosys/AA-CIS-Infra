# AA-869 — rollback readiness (Infra part)

## Decisions
- CIS ECR `aa-cis-dev-api` IMMUTABLE. Order: AA-CIS-App stops pushing `:latest` (CIS #798, deployed) first, then
  this apply; otherwise the next deploy would fail on the `:latest` re-push.

  Cost (D-19): CIS image ~440 MB → ~13 GB kept, about +0.7 USD/month at 0.10 USD/GB-month.
- The frozen `:latest` image also carries a `dev-` tag and ages out with rule 2; the Terraform task-def
  placeholder then names a missing tag, harmless (services ignore task_definition).
