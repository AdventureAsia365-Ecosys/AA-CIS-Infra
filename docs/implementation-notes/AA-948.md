# AA-948: the CRM proposal builder map's Mapbox token (AA-CIS-Infra part)

The proposal builder of AA-Partner draws its map with the shared map engine (canonical in AA-TripPlanner-Web
`frontend/lib/map-engine`, a byte copy in AA-Partner `web/lib/map-engine`). The web reads the public Mapbox token at
request time from `MAPBOX_PUBLIC_TOKEN` (AA-Partner `web/lib/mapConfig.ts`). This repo maps it into the task.

## Decisions

- The token is one more key of the existing secret `crm/dev/web` (`mapbox_public_token`), not a plain `environment`
  value and not a new secret: the repo is public (no value in tfvars), the execution role already reads `crm/dev/web`,
  and the key is written the way every other key of that secret is (`crm_dev_identity.py`, never Terraform).
- Mapped only while `crm_web_mapbox_enabled` is true (default false), the AA-1111 Sentry pattern: ECS refuses to
  start a task whose secret lacks a mapped key, so the flag turns on only after the key exists.
- `crm_dev_identity.py web-mapbox-token` accepts only a public token (`pk.<part>.<part>`) and refuses a secret
  `sk.` token, so a wrong paste can never reach a browser. `--mapbox-token -` reads stdin (no shell history).

## Changed

- `modules/environment/crm_web.tf`: variable `crm_web_mapbox_enabled`; the `MAPBOX_PUBLIC_TOKEN` secrets entry.
- `accounts/aa365/crm_variables.tf`, `accounts/aa365/environment.tf`: the pass-through variable (default false).
- `tools/identity/crm_dev_identity.py`: subcommand `web-mapbox-token`; tests in `tools/identity/tests/`.
- `tools/identity/README.md`: the subcommand row.
- `tools/terraform/tests/test_aa1004_environment_moves.py`: `crm_web_mapbox_enabled` added to `SLICE_2_SETTINGS`
  (every CRM setting declared in both the root and the module must be listed there; review fix).

## Tradeoffs

- No change of the flag in `terraform.tfvars` here: the key does not exist yet. The flip (one line,
  `crm_web_mapbox_enabled = true`) is a follow-up PR after the tech lead's hand step below.
- Without the flag (today) the CRM builder shows "Map not set up yet": not an error, and no Mapbox load is made.

## Should know
