# AA-890 / AA-888 — PR template, .bak cleanup and ADR index (AA-CIS-Infra)

## Decisions

- `.github/pull_request_template.md`: What / Why (`Refs AA-xxx`), a Plan summary section (roots, add / change /
  destroy, every destroy or replace explained), Risk and rollback, Cost (monthly cost per new resource, `App` tag;
  `Environment` comes from the provider default tags, DM-10.1), Docs checklist and Verification (Terraform Plan,
  fmt and validate, Secret Scan, migration copies then DB Migrate check/apply, apply only from `main`, live check
  after apply).
- Deleted `main.tf.bak` and `main.tf.bak2` (S243 plan N11, S241 U-42). Both were last changed in April 2026,
  nothing references them (`git grep`), and they hold only variable references (no literal secret values). The
  README row that warned about them is removed. `envs/` was already gone (AA-841).
- `docs/adr/README.md` (AA-888, S243 plan N9): no infra-only ADR exists yet, so the index lists the root ADRs this
  repo implements and starts an empty table.
- No PR-title workflow here: the S243 plan puts it in Booking and TripPlanner only (this repo is private and
  Actions minutes are limited).

## Changed

- No Terraform, workflow or script changed, so no plan is needed. `terraform fmt`/`validate` not applicable.
