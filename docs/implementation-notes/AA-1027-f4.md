# AA-1027 F4 (interim path) — CRM AI gateway on Amazon Nova Lite, acc2 (S266)

Session S266 (03/11/2026), Claude Code lane l5-crm-f4-path. Branch `feat/aa-1027-f4-crm-llm-acc2`. Refs AA-1027.
Source: the S265 re-scope comment on AA-1027 (tech lead: one real CRM draft on a cheap acc2 model through the gateway,
~0.001 USD, ledger row priced from the catalogue; the acc3 Haiku draft becomes a follow-up check). Companion PRs:
AA-Partner crm-042 (the draft route), root ADR 0009 decision 14 amendment.

## Decisions

- **Model: Amazon Nova Lite, `us.amazon.nova-lite-v1:0`.** The cheapest of the five acc2 chat models CIS migration
  324 catalogued and priced (0.077 / 0.308 USD per million tokens, AWS Price List API, us-west-1, 31/10/2026); it is
  already the acc2 fallback of eight CIS judge / validate stages (331-333), contract-smoked on acc2 in S263. Llama 4
  Scout / Maverick cost 2-3x more; Nova 2 Lite and Kimi K3 10-50x.
- **Task role, no `CRM_LLM_ROLE_ARN`.** acc2 is the account of the task; acc3 refuses every model (Error 002), so no
  assume-role leg.
- **Grant = `bedrock:InvokeModel` only.** Converse is authorised by that action; the CRM never streams, so no
  `InvokeModelWithResponseStream`. Resources: the us. profile ARN in this account and region, plus
  `foundation-model/amazon.nova-lite-v1:0` in us-east-1, us-east-2, us-west-1 and us-west-2 (a us. profile is checked
  against the foundation model in the member region that serves the call, tripplanner.tf). No regionless ARN and no
  `global.` profile. The account id comes from `var.account_id`.
- **Env prices = the catalogue prices.** The app requires `CRM_LLM_USD_PER_MTOK_IN` / `_OUT` with
  `CRM_LLM_PROVIDER=bedrock`, and an env price overrides the route's catalog price for that model (the ledger then
  says `pricing_mode = override`). Both are set to the CIS catalogue numbers (equal to the crm-042 route row), so the
  ledger cost is the catalogue price whichever source wins. Relaxing the app rule (prices optional) was weighed and
  left out: a second code PR and deploy for a label, not a number.
- **A switch, default off, on in tfvars** (`crm_llm_bedrock_enabled`), like `crm_scrub_guardrail_enabled`: off removes
  the env and the policy and the app falls back to its stub.
- **New file `crm_llm.tf`** (a parallel lane moves resources into modules); the only edit elsewhere is the one-word
  `local.crm_llm_env` in the `crm_api` task definition's env concat, plus its comment.

## Tradeoffs

- Writer stage on acc2 goes against root ADR 0009 decision 14 ("writers stay on Claude", acc2 only for judge /
  validate). Accepted by the tech lead for F4 (S265 re-scope); recorded as a Dev-only amendment in the root ADR. Dev
  has synthetic agencies only, every draft is a suggestion a human edits and sends (R39).
- One route entry, no acc2 fallback behind it: a failed Nova Lite call is a "reply by hand" draft. A second acc2
  entry would double the paid attempts for a path test.
