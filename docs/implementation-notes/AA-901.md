## Infra docs workflows on the `aa-ecosys-ci-bot` App token (root `docs/security/github-apps.md` part 7)

### Decisions

- `db-schema-dump.yml`, `docs-gen.yml` and `migration-copy-guard.yml` mint an installation token with
  `actions/create-github-app-token@v3` (inputs checked in its `action.yml`): `app-id: vars.AA_CI_BOT_APP_ID`,
  `private-key: secrets.AA_CI_BOT_PRIVATE_KEY`, `owner: AdventureAsia365-Ecosys`, `repositories: AA-Ecosys`, explicit
  `permission-*` inputs. The token is revoked by the action's post step when the job ends.
- Least privilege per job:
  - DB Schema Dump `dump` (main only): one token, `contents: write` + `pull-requests: write`, minted after every AWS
    step that produces the dump, right before the root checkout (`persist-credentials` stays the default, the drift
    step's `git fetch` uses it).
  - Docs Gen `render` (main only): two tokens. A `contents: read` token for the root checkout (still before the AWS
    steps: the render step checks runbook links against it; `persist-credentials: false`), and a separate
    `contents: write` + `pull-requests: write` token minted right before the PR step, after every AWS / Terraform
    step, used only there (push URL + `gh`).
  - Migration Copy Guard `retention-rows` (runs on `pull_request` too): `contents: read` only, minted only when a
    scoped dir has a copy.
- `HAS_ROOT_TOKEN` became `HAS_CI_BOT_APP` (variable and secret both set); the fail-closed messages name the App
  and both missing names.

### Changed

- `app-id` is used (the task's variable is the App ID); v3 marks `app-id` deprecated in favour of `client-id`, so
  the runs show a deprecation notice. Switching means a new variable holding the Client ID.
- Commits on the bot branches keep the `github-actions[bot]` author line; the PRs and pushes are made by the App.

### Should know

- Repo-level secret on a private GitHub Free repo: a same-repo PR that edits a workflow could read the key; the
  main-only guards stop the committed workflows from minting a write token off `main`, but cannot stop an edited
  workflow. CODEOWNERS on `.github/` is the future gate (ADR 0014).
- After merge: `ROOT_REPO_DOCS_TOKEN` is unused here; delete it and revoke the PAT once the first runs are green.
